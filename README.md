 # Expense Tracker Dashboard

A clean, interactive, and responsive full-stack web application designed to track personal budgets in real-time. This project features an interactive front-end user interface that communicates seamlessly with a back-end REST API to log individual expenses and monitor net remaining balances.

## 🚀 Key Functional Features
* **Full-Stack Separation:** Structured project split into front-end UI layouts and a backend server directory.
* **Real-time Backend Calculations:** Asynchronous communication updates total budget thresholds, expenditures, and remaining balances instantly across server data streams.
* **Responsive Visual Layout:** A modern interface designed with custom visual summary cards and clean breakdown ledger tables that adapt smoothly to desktop and mobile devices.
